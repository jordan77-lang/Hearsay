HearSay for Chrome

Work beside your course page. The extension opens HearSay in Chrome's side panel, so you can capture text from Canvas, Google Docs or any web page, listen to it, and add pronunciations to your class dictionary without leaving the page.

Download the Chrome extension (.zip)

Install

  1. Download hearsay-chrome-extension.zip.
  2. Extract the zip to a folder you will keep (for example Documents/HearSay-extension). The folder must contain manifest.json at the top level.
  3. Open chrome://extensions and turn on Developer mode.
  4. Click Load unpacked and select the extracted folder (not the .zip file).
  5. Pin HearSay from the puzzle-piece icon in the toolbar.

Use it on a course page

  1. Open the course page and select the text you want to check.
  2. Click the HearSay icon to open the side panel and choose your class.
  3. Choose Pull from page, then listen, get AI suggestions, and add pronunciations as on the website.

Prefer the website? Open HearSay. A Safari extension is coming later.
